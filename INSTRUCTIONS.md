# Screenshots Directory Instructions

Place your two genuine screenshots in this folder as required by the EWB Workbook:

1. `sample_run.png`:
   - Open PowerShell or Command Prompt.
   - Run `python phishing_checker.py`.
   - Enter one sample URL (for example, `http://192.0.2.10/account`).
   - Press `Windows + Shift + S`, select your terminal window showing the command, input, and detected warnings.
   - Save the image directly in this folder as `sample_run.png`.

2. `test_results.png`:
   - Open PowerShell or Command Prompt and run through the sample tests, OR open `tests/test_samples.md` in your editor.
   - Press `Windows + Shift + S` and select the window showing the verified test results.
   - Save the image directly in this folder as `test_results.png`.
